# `internal/messaging`

## Contract

`Decode` and the envelope (`docs/messaging.md`), read with [`strictjson`](strictjson.md); `Mailbox`: durable send with receipts, retry and id-reuse conflict, recipient, task and attempt checks, bounded ordered listing and acknowledgement, concurrent use (D15).
`StoreMailbox` implements it on the store.
`Wake` is the one wake for a message to the Director ([waking the Director](../messaging.md#waking-the-director)): over the narrow `WakeStore`, which `*store.Store` implements and the commands implement by opening the store per call, and the `DirectorPane` it types through, it types `WakeLine`'s counts into a running or recovering session's bound pane and records `woke`, records `queued` with its reason otherwise, and returns the recorded wake for a message already woken for, typing nothing.
When it types, `DueHandoffs` finds the session's task and context trigger crossings not yet announced, from the policy the session recorded, `FinishedTasks` and the context report, and the line ends with `HandoffLine`'s `; handoff due (<reasons>)`; each crossing typed is recorded with `RecordHandoffDue` and the message id, a conflict standing as a concurrent wake's record, and a wake that types nothing records none ([automatic handoff](../director.md#automatic-handoff)).
`WakeIdle` is the supervisor's idle line: the same line with nothing unread allowed, adding the idle trigger's next crossing, recorded with no message id, and returning the reason it typed nothing as a queued wake's.
`WakeLine` of no unread messages is `guildhall: 0 unread`.
`WakeResumed` is the resume's wake ([pause and resume](../director.md#pause-and-resume)): over the narrow `SessionReader` and the same `DirectorPane`, given the work waiting by kind, it types `ResumeLine`'s counts into a running or recovering session's bound pane and returns `woke`, and otherwise types nothing and returns `queued` with `nothing waiting` or `Wake`'s session and pane reasons; it records nothing, so each message's recorded wake stands.

## Tests

`envelope_test.go` (with `testdata/` encodings); `store_mailbox_test.go` runs the shared suite against real store files, closing and reopening them for restart; `wake_test.go`, written red first against a stubbed `Wake` and `WakeLine` ([red run](../evidence/director-wake-2026-10-22-red.txt)), on real store files with a recording pane: one line of exact counts per new message, never its text, nothing typed for a replayed send after a restart, each queued reason with nothing typed and the message still in the inbox, a recovering session woken, a nil pane queued, and a missing or Artisan message refused.
`handoff_test.go` was written red first against stubbed `DueHandoffs`, `HandoffLine` and `WakeIdle` ([red run](../evidence/director-handoff-triggers-2026-10-22-red.txt)), on real store files: the task trigger's suffix once per crossing at 2 and 4 finished tasks with each recorded against its message; the context trigger once at 72% and not again at 90% or for a torn report; two triggers joined, context first; triggers off at 0 and the context trigger off without a report path; a failed wake leaving the crossing for the next; the idle line's crossings 1 and 2, with the task crossing beside the second, and nothing typed or recorded for a paused session, no pane or a failed pane.
Its second idle assertion first indexed the wrong crossing, contradicting the line order the same test asserts, and was corrected when the implementation ran.
`wake_test.go`'s `WakeResumed` and `ResumeLine` tests were written red first against stubs ([red run](../evidence/director-checks-watch-and-resume-wake-2026-10-22-red.txt)): one line of counts for a resumed session with work waiting, the message's queued `paused` wake unchanged, each queued reason with nothing typed, a nil pane queued, and the line's format.
`messagingtest` gains no case
