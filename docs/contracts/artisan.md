# `internal/artisan`

## Contract

Process identity: `Lookup` and `Probe` by PID plus a boot-scoped creation token; a zombie is gone, a failed probe is unverified, never gone.
The containment seam the launcher consumes, `Unit`: start with verified membership, members by identity, interrupt, terminate (Unix only, `ErrUnsupportedRung` on Windows), kill, exited and close; a stop rung counts only when the unit is empty.
Each unit reports its `Containment` (kind, name, Linux detection reason), and `RecordContainment` writes it to the attempt directory as `containment.json`.
See [Artisan containment](../artisan.md#containment-unit) for the backends and Linux detection rules.
The control endpoint ([attempt-endpoint-af-unix](../decisions/0034-attempt-endpoint-af-unix.md)): `EndpointPath` with the hashed fallback and `ErrEndpointPath`; `Listen` with its `OwnerLookup` seam, `ErrNotOwner`, and the stale-file rule (`ErrEndpointAnswers`, `ErrEndpointUnknown`); the `EndpointHandler` the launcher supplies for `status`, `stop` and `cancel`; `Close`; and `Call` with `ErrEndpointMismatch`, `ErrEndpointRequest` and `ErrEndpointProtocol`.
The stop ladder ([decision](../decisions/0041-stop-ladder-precedence.md)): `Launcher` with `NewLauncher`, `Run`, and `Status`, `Stop` and `Cancel` as the endpoint's handler; the `AttemptFiles` seam for the result and cancel marker; precedence under the attempt lock and one `Outcome` in `outcome.json` (`OutcomeSchema`), read with `ReadOutcome`, which refuses a malformed file with `ErrInvalidOutcome` and a newer one with a wrapped `strictjson.ErrNewerSchema`; `Ladder` and `DefaultLadder`, each rung logged to `events.jsonl` and successful only when the unit is empty; `StopSignals`; `ErrDecided`, `ErrNotEmpty` and `ErrLauncherRan`.
See [stop ladder](../artisan.md#stop-ladder).
The heartbeat ([heartbeat](../artisan.md#heartbeat)): `Heartbeat`, `HeartbeatFile`, `HeartbeatSchema` (`guildhall.attempt-heartbeat/1`), `DefaultHeartbeatInterval`, `WriteHeartbeat`, `ReadHeartbeat` with `ErrNoHeartbeat`, `ErrInvalidHeartbeat` and a wrapped `strictjson.ErrNewerSchema`, and the `LauncherConfig` fields `Key`, `HeartbeatInterval` and `LastOutput`; written atomically from the supervision loop with an increasing sequence.
`NewUnit` returns this platform's unit; `Contained` lists a recorded unit's live processes from outside its launcher, for [reconcile](reconcile.md).
Requests and replies are protocol `guildhall.attempt-control/1`, decoded with [`strictjson`](strictjson.md); a request that is unversioned, newer, or carries a duplicate or undeclared field at any depth is refused before identities are matched or any handler runs ([decision](../decisions/0038-endpoint-protocol-v1.md)).

## Tests

`TestRecordContainment` was written with the function and passed on first run; it did not precede implementation.
The review retrofit is explicitly authorized.
Its atomic-replacement assertion keeps a hard link to the previous record and requires that record to remain unchanged after replacement.
Behavioral failure evidence is checked by running this test against isolated Go overlays with (1) the JSON key changed from `containment` to `kind`, and (2) a direct destination write instead of temporary-file rename.
These mutations must fail the key and prior-record assertions respectively; this is retrofit evidence, not a claim of test-first development.

`unit_test.go` runs the shared suite against the platform backend on each runner; `unit_linux_test.go` runs it against the cgroup backend (skipped with the detection reason when no cgroup v2 is delegated) and the subreaper fallback, and checks that an orphaned escape is reported by `Escapes`; `cgroup_internal_linux_test.go` (the detection table, stale nonmember PIDs, refused names); `cgroup_linux_test.go` (`cgroup.kill` emptying the unit after a test-binary grandchild acknowledges setsid and its separate process group is checked, and `Close` removing the cgroup); `containment_test.go` (the attempt-directory record and atomic replacement); `containment_store_test.go` (written red first: each declared kind's description, and this platform's started unit with its worker identity, stored in a real store as an ownership record and read back recoverable); `fakeunit_test.go` runs it against `fakeUnit`, the launcher's double; `unit_unix_internal_test.go` (leader check, close retry after a refused kill, start rollback killing descendants); `unit_internal_windows_test.go` (a process outside the job is not a member; interrupt after worker exit and retained-handle cleanup); `unit_internal_linux_test.go` (failed exec restores foreground ownership using a controlling pseudo-terminal); `identity_test.go` (real processes); `identity_windows_test.go` (exit code 259 with a retained process handle).

`endpoint_test.go` binds real AF_UNIX sockets in a short temporary state directory on each runner, with the test binary playing an unrecorded process that holds a socket; `endpoint_linux_test.go` keeps a socket that refuses access.
Written red first against stubs: the path and its limit boundary with the hashed fallback, bind-after-own ordering (no record, another launcher, then the recorded owner), the stale-file rule (a killed process's socket and a closed listener's socket removed; an answering socket, a directory and an unreachable socket refused and kept), dispatch of `status`, `stop` and `cancel`, handler errors, attempt and launcher mismatch, status answered during a blocked stop and the caller's deadline, and `TestEndpointWithStoreOwnership` against a real store record (refused before ownership and while another launcher owns the attempt, bound after `TakeOwnership`, recorded by `UpdateOwnership`, refused once `FinishAttempt` releases it).
`TestEndpointLineProtocol` pins the scratch launcher's line framing and malformed-request reply, extended with expected attempt and launcher fields; its status request now carries the version 1 schema, as the [protocol decision](../decisions/0038-endpoint-protocol-v1.md) requires.
`endpoint_protocol_test.go` was written red first: `TestEndpointRefusesUnsupportedRequestsBeforeDispatch` sends future, next, missing, zero and foreign versions, duplicate `schema` and `op`, an unknown and a case-variant field, and a `launcher` with an unknown or duplicate field, a string PID, a string or a list, for each of `status`, `stop` and `cancel`, and asserts a version 1 error reply and no handler call; `TestCallRefusesUnsupportedReplies` answers `Call` from a raw socket with a future or missing version, invalid JSON, unknown or duplicate fields and unknown fields nested in `state` and its members, and expects `ErrEndpointProtocol`; `TestEndpointAcceptsVersionedRequest` was red until the reply carried the schema.
The identity-mismatch, stale-socket, long-path fallback, bounded-line and blocked-stop tests above pin the rest of the endpoint across the change and passed unchanged.
`TestEndpointRejectsMismatchedTargetsBeforeDispatch` checks that a replacement owner receives no handler calls from stale-owner requests, and that wrong or missing target identities are refused for every operation.
The stale-socket and answering-socket cases pin scratch L21.

`launcher_test.go` runs `artisantest.RunStopContract` against the platform backend and `fakeUnit`; written red first against stub bodies, with every case failing.
After the red commit one harness detail changed, not an expectation: the decided-attempt case calls `Run` directly and now marks the case's run as returned.
The cancel-before-start case was added with its fix during implementation and was checked by removing the fix, which makes it fail.
It pins scratch ladder behaviour: rung order and bounds, emptiness as the only success, the stop-after-result no-op and the late-result rejection.
`outcome_test.go` was written red first against a `ReadOutcome` holding reconcile's lenient read: the accepted file, a missing file, a newer schema, and unversioned, foreign-schema, unknown-field, nested-unknown, duplicate-key, trailing-data, unknown-state and torn refusals; the stop contract now checks each written outcome through `ReadOutcome`.
`heartbeat_test.go` was written red first against a `WriteHeartbeat` without validation and the unversioned lenient reader: the file round trip with its schema, refused invalid writes leaving no file, and the newer-schema and malformed refusals.
The heartbeat, `NewUnit` and `Contained` are exercised by the [reconcile tests](reconcile.md#tests), written red first against stubs; `LauncherConfig.Key` became required, so the stop contract's launchers name `artisantest.StopKey`.
