# `internal/artisan`

## Contract

Process identity: `Lookup` and `Probe` by PID plus a boot-scoped creation token; a zombie is gone, a failed probe is unverified, never gone.
The containment seam the launcher consumes, `Unit`: start with verified membership, members by identity, interrupt, terminate (Unix only, `ErrUnsupportedRung` on Windows), kill, exited and close; a stop rung counts only when the unit is empty.
Each unit reports its `Containment` (kind, name, Linux detection reason), and `RecordContainment` writes it to the attempt directory as `containment.json`.
See [Artisan containment](../artisan.md#containment-unit) for the backends and Linux detection rules.
The control endpoint ([attempt-endpoint-af-unix](../decisions/0034-attempt-endpoint-af-unix.md)): `EndpointPath` with the hashed fallback and `ErrEndpointPath`; `Listen` with its `OwnerLookup` seam, `ErrNotOwner`, and the stale-file rule (`ErrEndpointAnswers`, `ErrEndpointUnknown`); the `EndpointHandler` the launcher supplies for `status`, `stop` and `cancel`; `Close`; and `Call` with `ErrEndpointMismatch`, `ErrEndpointRequest` and `ErrEndpointProtocol`.
The stop ladder ([decision](../decisions/0041-stop-ladder-precedence.md)): `Launcher` with `NewLauncher`, `Run`, and `Status`, `Stop` and `Cancel` as the endpoint's handler; the `AttemptFiles` seam for the result and cancel marker; precedence under the attempt lock and one `Outcome` in `outcome.json` (`OutcomeSchema`), read with `ReadOutcome`, which refuses a malformed file with `ErrInvalidOutcome` and a newer one with a wrapped `strictjson.ErrNewerSchema`; `Ladder` and `DefaultLadder`, each rung logged to `events.jsonl` and successful only when the unit is empty; `LogAdvance`, the `advance` event a launcher's [watcher](../running.md#the-watcher) advance logs there; `StopSignals`; `ErrDecided`, `ErrNotEmpty` and `ErrLauncherRan`.
See [stop ladder](../artisan.md#stop-ladder).
The heartbeat ([heartbeat](../artisan.md#heartbeat)): `Heartbeat`, `HeartbeatFile`, `HeartbeatSchema` (`guildhall.attempt-heartbeat/1`), `DefaultHeartbeatInterval`, `WriteHeartbeat`, `ReadHeartbeat` with `ErrNoHeartbeat`, `ErrInvalidHeartbeat` and a wrapped `strictjson.ErrNewerSchema`, and the `LauncherConfig` fields `Key`, `HeartbeatInterval`, `LastOutput` and `Beat`, which is called with each beat written, and `LogStall`, the `worker-stalled` event of a launcher's stall send; written atomically from the supervision loop with an increasing sequence.
Resume ([resume](../artisan.md#resume)): `Kill` ends a process only while its PID and token still match; `Sweep` kills what is still in a recorded unit from outside its launcher (job terminated by name, `cgroup.kill` then removal of an empty cgroup, process-group members by `Kill`), refusing an unknown kind with `errors.ErrUnsupported` and proving nothing until `Contained` is empty; `Settle` decides an attempt whose launcher is gone from its files with the launcher's precedence, keeping an existing `outcome.json`, under the caller's attempt lock.
`AttemptKey` owns the attempt layout: `Dir(stateDir)` is `<stateDir>/<repository>/<task>/<step>-<n>`, `AttemptID()` is `<step>-<n>` and `ResultFile` is `result.json`; the interpreter prepares that directory and the launcher runs in it, and neither spells the layout itself.
The process inventory ([harness](../artisan.md#harness)): `ProcessRecord`, an identity with a role; `RecordProcess` writes `<role>-<pid>.json` atomically, creating the directory; `ReadProcessRecords` reads every such file in name order, refusing a record without a positive PID, a token or a role, or one not under its own name, with `ErrInvalidProcessRecord`; the fake Artisan, the `artisantest` worker and the lab harness are its writers and readers.
`NewUnit` returns this platform's unit; `Contained` lists a recorded unit's live processes from outside its launcher, for [reconcile](reconcile.md).
Requests and replies are protocol `guildhall.attempt-control/1`, decoded with [`strictjson`](strictjson.md); a request that is unversioned, newer, or carries a duplicate or undeclared field at any depth is refused before identities are matched or any handler runs ([decision](../decisions/0038-endpoint-protocol-v1.md)).
