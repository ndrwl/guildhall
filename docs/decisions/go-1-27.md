# The module targets Go 1.27

## Context

`go.mod` needed a language version when the module was created.

## Decision

`go.mod` declares Go 1.27, the current stable release line when the module was created.
CI installs the newest 1.27 patch release through `go-version-file`.

## Consequences

The language version moves only by a pull request that records a superseding decision.
