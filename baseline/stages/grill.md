# Grill

Find out what the task really asks for before anyone plans it.
List the questions a careful engineer would ask about the change: its users, its scope, its edge cases and what done looks like.
Answer each from the task, the repository and its documents, and say where each answer came from.
Mark every question you could not answer with confidence, so the Guildmaster can settle it.
Write the required `notes` port as a UTF-8 Markdown document at `notes.md` in your working directory.
