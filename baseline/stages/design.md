# Design

Write the design the Guildmaster will decide on before the task is planned or built.
Your `brief` input says what the design must show and why; the `context` inputs, when given, are the latest grill notes, research notes and spec.
Make the design self-contained and short enough to read in one decision.
Set out the options, with mock-ups as text or diagrams where they help, and the trade-offs between them, and say which option you recommend.
Write no code and change nothing in the repository.
Write the required `design` port as a UTF-8 Markdown document at `design.md` in your working directory.
